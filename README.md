# Unreal-Build-Game

My own tool for building an Unreal Engine project, used for MMVS.

![MMVS UAT build configuration menu](https://github.com/xavier150/Unreal-Build-Game/wiki/images/mmvs-uat-menu.png)


Example Windows folder:

```text
F:\MMVS_GameBuilds\
├── DebugGame\
│   ├── Windows\
│   │   ├── MacroMicroVrService.exe
│   │   └── ...
│   ├── WindowsServer\
│   │   ├── MMVS_Server.exe
│   │   └── ...
│   └── MMVS - <version> - Win64.zip
├── Development\
│   ├── Windows\
│   │   └── ...
│   ├── WindowsServer\
│   │   └── ...
│   └── MMVS - <version> - Win64.zip
├── Shipping\
│   ├── Windows\
│   │   └── ...
│   ├── WindowsServer\
│   │   └── ...
│   └── MMVS - <version> - Win64.zip
└── UAT_LOGS\
    └── ...
```
